# 认知生产线 V2 设计

## 定位

`daily-info-radar` 在个人认知生产线里负责上游过滤：

> 外部信息源 -> 候选池 -> AI/规则筛选 -> 认知生产线视图 -> 精读 -> 认知增量卡片 -> 内容输出 -> 周复盘

V2 的目标不是增加更多信息源，而是让每条精选信息天然带上后续处理线索：

- 是否值得精读；
- 可能更新什么判断；
- 能否转化为内容；
- 应该进入待读、追踪还是直接跳过。

## 当前 MVP

### 已保留

- 多源采集；
- 24 小时时效窗口；
- 去重与公平采样；
- AI / heuristic 分析；
- 普通日报 Markdown；
- 飞书卡片推送；
- Obsidian 待读清单。

### 新增

- `cognitiveSignal.score`：认知增量潜力分；
- `cognitiveSignal.priority`：`精读` / `扫读` / `追踪` / `跳过`；
- `cognitiveSignal.tags`：判断更新、能力增强、行动线索、创作素材、趋势信号、系统优化；
- `cognitiveSignal.hypothesis`：这条信息可能更新什么判断；
- `cognitiveSignal.contentAngle`：可以转化成什么内容角度；
- `briefs/production/{date}.md`：每日认知生产线 Markdown。

## 每日使用方式

1. 早上运行或接收 `npm run daily` 生成的日报。
2. 打开 `briefs/production/{date}.md`。
3. 从「今日精读入口」只选 1 条精读。
4. 精读后填写卡片里的「旧判断 / 新判断 / 变化原因」。
5. 把卡片转成短内容、长文素材或周复盘素材。

## 第一阶段不做

- 不做完整资讯站；
- 不做个性化推荐；
- 不做复杂会员系统；
- 不自动抓取全文并生成长文；
- 不让 AI 替代最终判断。

## 下一阶段建议

1. 增加人工反馈命令：`已精读`、`无增量`、`转选题`。
2. 记录信源贡献度：统计哪些来源持续产出高分认知候选。
3. 增加周复盘命令：自动汇总本周精读、卡片、选题和低价值来源。
4. 接入 Obsidian 卡片目录：从生产线 Markdown 生成独立认知增量卡片。
5. 等连续跑通 4-6 周后，再考虑静态资讯页或邮件订阅。
